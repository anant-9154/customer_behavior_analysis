# Customer Behavior Analysis | End-to-End Data Analytics Project

## Overview
This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, revenue trends, and sales performance across different product categories and customer segments.

The project follows an end-to-end data analytics workflow, starting with data loading and exploration in Python, data cleaning and preprocessing, SQL-based analysis using MySQL, and interactive dashboard development using Power BI.

The objective is to transform raw customer data into meaningful insights that can support data-driven business decisions.

## Dataset
- **Dataset:** Customer Shopping Behavior Dataset
- **Data Type:** Customer purchase and shopping information
- **Key Attributes:** Customer ID, Age, Gender, Category, Item Purchased, Purchase Amount, Subscription Status, Shipping Type, Review Rating, and other shopping-related attributes.

## Tools & Technologies
- **Python:** Data loading, exploration, cleaning, and preprocessing.
- **Pandas & NumPy:** Data manipulation and transformation.
- **MySQL:** Data querying, aggregation, filtering, and business analysis.
- **Power BI:** Interactive dashboard development and data visualization.
- **Jupyter Notebook:** Python development and analysis.

## Project Workflow

### 1. Data Loading & Exploration (Python)
- Imported the dataset into Jupyter Notebook using Pandas.
- Examined dataset dimensions, columns, and data types.
- Explored statistical summaries and identified initial data patterns.
- Performed Exploratory Data Analysis (EDA).

### 2. Data Cleaning & Preprocessing
- Identified and handled missing and duplicate values.
- Checked and corrected inconsistent data types.
- Standardized categorical values.
- Prepared the dataset for further analysis.

### 3. SQL Analysis (MySQL)
- Imported the cleaned dataset into MySQL.
- Performed business-oriented SQL analysis.
- Used aggregate functions, GROUP BY, HAVING, WHERE, and ORDER BY.
- Analyzed customer segments, purchasing patterns, sales, and revenue across product categories.
- Used SQL queries to extract meaningful business insights.

### 4. Power BI Dashboard
- Connected the analyzed dataset to Power BI.
- Created KPI cards to highlight key business metrics.
- Developed interactive charts and visualizations.
- Added slicers and filters for dynamic data exploration.
- Designed a customer behavior dashboard to analyze customer segments, subscription status, revenue, and sales performance.

## Dashboard Preview

The interactive Power BI dashboard provides an overview of customer shopping behavior through the following metrics and visualizations:

**Key Performance Indicators (KPIs):**
- Total Customers: 3.9K
- Average Purchase Amount: $59.76
- Average Review Rating: 3.75

**Dashboard Insights:**
- Customer subscription distribution (Yes/No).
- Revenue by product category.
- Sales by product category.
- Revenue distribution across different age groups.
- Sales performance across customer age groups.
- Interactive filtering by gender, subscription status, category, and shipping type.

## Results & Business Insights
- Evaluated customer purchasing behavior across different product categories.
- Identified Clothing as the leading category in both revenue and sales.
- Analyzed subscriber distribution, with approximately 27% subscribed customers.
- Compared purchasing patterns across Young Adult, Middle-aged, Adult, and Senior customer segments.
- Developed an interactive dashboard to make customer and sales performance analysis easier.

## How to Run

**1. Clone the repository**
```bash
git clone https://github.com/your-username/customer-behavior-analysis.git
```

**2. Navigate to the project directory**
```bash
cd customer-behavior-analysis
```

**3. Install the required Python libraries**
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**4. Run the Jupyter Notebook**

Open the notebook and execute the cells to perform data loading, EDA, and data cleaning.

**5. Perform SQL Analysis**

- Import the cleaned dataset into MySQL.
- Execute the SQL queries provided in the project repository.

**6. Open the Power BI Dashboard**

- Open the `.pbix` file using Power BI Desktop.
- Configure the data source if required.
- Explore the dashboard using interactive filters and visualizations.
